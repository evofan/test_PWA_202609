[https://shanabrian.com/web/javascript/zero-padding.php](https://shanabrian.com/web/javascript/zero-padding.php)  
>簡単な解説（ES6以降の場合）  
>引数の桁数から対象の数字の桁数を引いて、その数をstring.repeatメソッドで0を繰り返します。  
>結合した0の文字を対象の数字と結合することで、ゼロ埋め（ゼロパディング）を実現します。
